Tu redacción, sin tocar código.

Accede al editor y publica artículos en la web. Las publicaciones se guardan en GitHub y activan el despliegue automático.

Importante: GitHub Pages no tiene un servidor de autenticación. La contraseña de esta pantalla es solo una barrera visual, no una protección real. Para guardar cambios se exige además un token de GitHub con permisos limitados al repositorio. Nunca compartas ese token.

La web no guarda el token: si quieres no tener que pegarlo cada vez, deja que el gestor de contraseñas de tu navegador lo recuerde. Para crear uno: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Limítalo a este repositorio y concede solo Contents: Read and write.

Cómo promocionar OpenKayak

La página principal ya conserva la sección dedicada a OpenKayak. Usa la categoría OpenKayak para publicar novedades, tutoriales, funciones del reloj y mejoras de la aplicación. Los artículos aparecen en la sección de guías de la portada.

Los cambios se publican cuando termina el flujo de GitHub Actions. La primera publicación puede tardar unos minutos.
